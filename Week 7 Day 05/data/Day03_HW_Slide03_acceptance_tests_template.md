## Checklist

- [ ] Each test checks something the analyst can see or do, not how the code works
- [ ] At least one test is about the edge of the feature (nothing to show, an empty value, going back and forth)
- [ ] Each test fails before the feature exists, for the right reason
- [ ] Each test uses a `data-testid` or an API response, never a CSS class
