# ENG-402 · Score a run against the expert's labels

**Type:** feature · **Priority:** Must · **Day 4, Activity 1**

## Story

As the FDE, I want every run of the prototype scored field by field against Tom's labels, overall, per field and per slice of the data, so that I can see where it fails and prove whether a fix worked.

## Acceptance criteria

1. `score_run(outputs, labels, slices)` in `backend/app/evaluation/metrics.py` returns a `RunScore` exactly as its docstring describes:
   - a field is right when `norm(value) == norm(label)`: case, spaces and punctuation do not matter
   - **overall**, **per_field** (in the order of `FIELDS`) and **per_slice** (all four fields of each case in the slice, slices sorted)
   - **errors**: every wrong field, sorted by case, then by field order
   - only cases in both `outputs` and `labels` count; a missing field counts as ""
2. On **Evaluation → Error analysis**, **Run the prototype on all 50** shows the accuracy for each field and lists every wrong field next to what Tom says.

## Files you change

- `backend/app/evaluation/metrics.py`: fill in `score_run()`. Nothing else.
