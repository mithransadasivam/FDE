# Software Request Process

1. Check the Company Portal first. Most common tools are already listed and install instantly.
2. If the software is not listed, raise a "Software request" ticket with the name, version, the business reason and your manager's name.
3. The security team reviews the request. Standard review takes up to 3 working days.
4. If approved, IT installs it or adds it to the Company Portal.

## Licence costs
- Free software with an acceptable licence is usually approved quickly.
- Paid licences need your manager's budget approval before the request is processed.

## Not allowed
Cracked or pirated software, peer-to-peer file sharing tools and cryptocurrency miners are never approved.
