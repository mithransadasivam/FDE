# Backup and Recovery Runbook

## Server backups
- Daily backups run at 02:00 and are kept for 30 days.
- Monthly backups are kept for 12 months and stored off-site.
- Backups are encrypted with AES-256.

## Restoring a file or server
1. Open a ticket in the service desk portal.
2. Give the server name, the file path, and the date you want to restore from.
3. Standard restore requests are completed within 4 working hours.

## Laptops
Laptop files in the Documents folder are synced to cloud storage (NorthDrive). Files saved only on the Desktop or in Downloads are not backed up.

## Testing
The recovery process is tested every quarter by the infrastructure team.
