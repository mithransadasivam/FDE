# RB-01 · Database unavailable

Fictional runbook. Used for: db-core.

Steps marked [READ] only look; steps marked [CHANGE] need approval (policy section 5).

1. [READ] `check_service_status`: Check the primary and the replica: is the primary accepting connections?
2. [READ] `check_replication_lag`: Check the replica's replication lag. Continue only if it is under 30 seconds.
3. [CHANGE] `failover_db`: Fail over to the replica.
4. [READ] `check_dependants`: Check that the services that depend on the database have recovered.
