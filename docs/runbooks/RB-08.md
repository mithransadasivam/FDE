# RB-08 · Network latency

Fictional runbook. Used for: vpn-gw.

Steps marked [READ] only look; steps marked [CHANGE] need approval (policy section 5).

1. [READ] `check_latency_trend`: Check latency for the last hour. Ignore spikes that cleared within 15 minutes.
2. [READ] `check_tunnel_count`: Check how many tunnels are open.
3. [CHANGE] `restart_tunnel`: Restart the busiest tunnel, only if latency has stayed high for over 15 minutes.
