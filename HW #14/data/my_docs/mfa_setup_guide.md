# Multi-Factor Authentication (MFA) Setup

Every Northwind account must use MFA. We use the Northwind Authenticator app.

## Setting up MFA on a new phone
1. Raise a ticket titled "Reset MFA" so the service desk can clear your old MFA registration.
2. Once the ticket is resolved, install Northwind Authenticator from the App Store or Google Play.
3. Sign in to any work app. When asked, scan the QR code shown on screen with the app.
4. Enter the six-digit code to finish.

## Lost or stolen phone
Call the service desk on extension 4357 straight away, at any hour. They will lock your MFA registration so nobody else can use it.

## Backup codes
When you first register, the app shows 8 single-use backup codes. Store them in the company password manager, not on paper.

## Notes
- Codes refresh every 30 seconds.
- SMS codes are not allowed as an MFA method.
