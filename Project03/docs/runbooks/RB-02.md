# RB-02 · Web application slow or high memory

Fictional runbook. Used for: payportal, hr-selfservice, intranet.

Steps marked [READ] only look; steps marked [CHANGE] need approval (policy section 5).

1. [READ] `check_memory_trend`: Check memory on each node for the last hour.
2. [READ] `check_recent_deploys`: Check for a deploy in the last 24 hours. If there was one, tell the owning team.
3. [CHANGE] `restart_service`: Restart the affected node only, one node at a time, never all nodes together.
