# ENG-102 · Measurable success criteria and the use-case matrix

**Type:** feature · **Priority:** Must · **Day 1, Activity 4**

## Story

As the FDE, I want every success criterion checked for what is missing, and the candidate use cases shown on a value-against-feasibility matrix, so that the client agrees measurable targets and a first use case we can defend.

## Part A · Backend: `check_criterion()`

In `backend/app/discovery/criteria.py`, return the problems with a criterion as texts from `PROBLEMS`, in this order:

| Key | When |
|---|---|
| `vague` | the metric has fewer than 4 words |
| `no_target` | `target` is empty |
| `no_baseline` | only for `kind == "business"`, when `baseline` is empty |
| `no_unit` | `unit` is blank |
| `wrong_way` | baseline and target are both set and the target is not better in the criterion's direction |
| `no_method` | `measured_how` has fewer than 10 characters, ignoring spaces at the ends |
| `no_owner` / `no_deadline` | `owner` / `by_when` is blank |

An empty list means the criterion is measurable.

## Part B · Frontend: `UseCaseMatrix`

In `frontend/src/components/UseCaseMatrix.tsx`, replace the placeholder with an SVG chart:

- **Axes:** feasibility 1–5 left to right, value 1–5 bottom to top, both labelled.
- **Quadrants:** split at 3 on both axes, labelled *Quick wins* (top right), *Big bets* (top left), *Fill-ins* (bottom right) and *Not now* (bottom left). Tint *Quick wins* teal-50.
- **One bubble per use case**, showing its id, coloured by risk: 1–2 teal `#0E8F7E`, 3 amber `#D98E04`, 4–5 ember `#E8552F`, with a short name underneath.
- **Excluded use case** (non-empty `excluded_reason`): a dashed grey outline, crossed out, labelled *out of scope*, and not clickable.
- **First choice:** an ember ring and a ★ before its name.
- Clicking a bubble calls `onPick(useCase)`.
- **Test ids:** `data-testid="usecase-matrix"` on the `<svg>`. On each bubble's `<g>`: `data-testid="uc-<id>"`, plus `data-first` and `data-excluded` set to `"true"` or `"false"`.

Keep the props as they are: `{ useCases: UseCase[]; onPick?: (u: UseCase) => void }`. Use only SVG and Tailwind, with no new packages.
