# ENG-101 · Findings with evidence

**Type:** feature · **Priority:** Must · **Day 1, Activity 3**

## Story

As the FDE, I want the discovery transcript turned into findings, each with the speaker and the exact words that support it, and every quote checked by code, so that nothing we send the client is invented.

## Acceptance criteria

1. `extract_findings(transcript, client)` asks the model through `ask_json(client, FINDINGS_PROMPT, transcript, ExtractedFindings, task="findings")` and returns `Finding` objects numbered `F01`, `F02`, … in the order the model returned them, with `evidence_ok` left as `None`.
2. `verify_evidence(findings, transcript)` sets `evidence_ok` to `True` only when the quote appears word for word in something **that speaker** said. It ignores case, extra spaces, curly quotes and Markdown asterisks. It keeps every finding, in the same order, with the same ids.
3. On the Findings tab, **Extract findings** shows the cards with their quotes, a green or red evidence badge on each, and the pain-point matrix. The screen is already built: only the backend is missing.

## Files you change

- `backend/app/discovery/findings.py`: fill in `extract_findings()` and `verify_evidence()`. Nothing else.

`utterances()` in the same file already splits the transcript into `(speaker, words)` pairs.
