# File Sharing and Storage

## NorthDrive
- Every user has 1 TB of personal storage in NorthDrive.
- Team folders are created by request and owned by the team lead.

## Sharing files
- Share with a link set to "People in Northwind" by default.
- Sharing with external people needs the "Share externally" option, and links expire after 30 days.
- Never share confidential files by public link ("Anyone with the link").

## Deleted files
Deleted files stay in the recycle bin for 93 days. After that they cannot be recovered except from backups, which only hold files for 30 days.

## USB drives
USB storage is blocked on company laptops. Use NorthDrive instead.
